# Références héros — Arin & Lyra (Layer)

| Fichier | Usage |
|---------|--------|
| `arin-spritesheet-layer.png` | Spritesheet Arin (5×8, fond vert) |
| `arin-ref-v2.png` | Portrait Arin (backup) |
| `lyra-spritesheet-layer.png` | Spritesheet Lyra (6×8, fond vert) |
| `lyra-ref.png` | Portrait Lyra (fond noir) |

Rebuild gameplay :

```bash
npm run build:heroes          # Arin (5 frames)
npm run build:heroes:female   # Lyra (6 frames)
```
